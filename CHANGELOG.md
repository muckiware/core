# Changelog

All notable changes to `muckiware/core` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow the
`version` field in `composer.json` (release tag `v<version>`).

## [Unreleased]

### Changed
- Replaced Shopware's `StoreClient` with `Muckiware\Core\Framework\Store\Services\StoreClient`.
  The extension listing (`/api/_action/extension/installed`) and the store API endpoints
  (`/api/_action/store/updates`, `/license-violations`, `/plugin/search`) no longer send the
  installed extensions to `api.shopware.com` (`/swplatform/pluginupdates`,
  `/swplatform/licenseenvironment`, `/swplatform/environmentinformation`).

## [0.1.0.1] - 2026-11-27

### Changed
- Require `shopware/core` `v6.7.16.2` (was `v6.7.16`)

### Fixed
- Added `Framework/Resources/config/routes_overwrite.php`, mirroring Shopware's route overwrites.
  `UserController` and `IntegrationController` routes are now loaded after the generic DAL API
  routes, so `api.user.update`, `api.user.create` and `api.integration.*` reach their dedicated
  controllers again. Previously, saving a user profile or editing a user in the administration
  failed with `403 API access for entity "user" not allowed.`

## [0.1.0.0] - 2026-11-11

### Added
- `KernelBootstrap` selects the front controller kernel (installer vs. application) for the
  `public/index.php` generated by the muckiware Flex recipe
- PHPUnit setup and unit tests for `KernelBootstrap` and `InstallerKernel`

### Changed
- The installer resolves the project dir explicitly or via the Composer root package
- Tests and CI config are excluded from the dist archive
- The release workflow triggers the MuckiSafe image build after a release

## [0.0.3.0] - 2026-11-10

### Changed
- Updated Composer requirements

### Removed
- `ReverseProxyCompilerPass` and `ContainerVisibilityCompilerPass` loading in the Framework bundle

## [0.0.2.0] - 2026-11-06

### Added
- Web installer (`Muckiware\Core\Installer\InstallerKernel`) showing the Muckidrive version
- README
- Release workflow (tag + GitHub release when `main` is merged into `release`)
